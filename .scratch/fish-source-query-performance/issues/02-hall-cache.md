# 02: 复用未变化的鱼厅产出计算

**What to build:** 在现有正式模拟中复用原源规则的鱼厅计算结果，动态余额与观察时点保持实时。

**Blocked by:** 01：建立可复现的性能与结果对照.

**Status:** ready-for-agent

- [x] 缓存依赖覆盖完整鱼实例、鱼厅与真实倍率；不得只按鱼数量或对象引用判断。
- [x] 升级、捕获、孵化、出售、上阵、撤下、换位、神兽参考鱼和相关重生变化立即生效。
- [x] 每次查询返回当前余额、槽位待领、revision；返回值修改不污染缓存和下一次查询。
- [x] 缓存按会话隔离且不写入 checkpoint；查询不改变随机、时间或源状态。
- [x] 已有 Lua 会话回归与正式 smoke/首日差分通过，单项收益单独记录。
- [x] 同步受影响的模块导航与契约说明。
