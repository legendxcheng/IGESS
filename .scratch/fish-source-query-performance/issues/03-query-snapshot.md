# 03: 在单次查询中复用一致存档快照

**What to build:** 相关状态投影共享同一观察快照，减少重复复制，保留独立返回值和错误行为。

**Blocked by:** 01：建立可复现的性能与结果对照.

**Status:** ready-for-agent

- [x] 仅在同步只读查询范围内共享独立快照，不跨命令、结算、回调或会话。
- [x] 保留原公开查询校验，不暴露权威可变存档，不全局替换存档服务。
- [x] 重复观察、返回值修改、跨会话、查询选项与失败路径测试通过。
- [x] 状态、资格、图鉴、枪与库存变化及时反映，不用旧成功值遮蔽错误。
- [x] 已有 Lua 会话回归与正式 smoke/首日差分通过，单项收益单独记录。
- [x] 同步受影响的模块导航与契约说明。
