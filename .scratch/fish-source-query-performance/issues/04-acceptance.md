# 04: 完成组合优化的一周性能与恢复验收

**What to build:** 通过真实首日和一周运行证明提速及结果等价，交付可归因的报告、验证记录和审查结论。

**Blocked by:** 02：复用未变化的鱼厅产出计算；03：在单次查询中复用一致存档快照.

**Status:** ready-for-agent

- [x] 组合优化的四份核心产物逐字节一致，源历史、随机、revision、行为存档和最终状态符合规格。
- [x] 连续/恢复、准确/批量、大数、满包孵化及待完成副作用相关回归通过；不放宽跨版本存档身份校验。
- [x] 首日和一周至少三组同机、同环境、同输入串行交替测速，不带性能探针、不并行测试。
- [x] 一周三组配对均更快且中位数耗时不超过基线一半（用户追加目标：至少 2 倍速度），首日无可重复回退；波动时按规格扩至五组，不能证实收益不标通过。
- [x] 记录每次耗时、阶段耗时、中位数及范围、节省秒数和比例、源码/适配器/导表身份与正式报告。
- [x] 完成类型检查、完整测试套件一次和双轴代码审查，说明失败或跳过的实际原因。
- [x] 更新受影响说明与技能，提交仅本次改动；不构建或发布 GameBalancer。
