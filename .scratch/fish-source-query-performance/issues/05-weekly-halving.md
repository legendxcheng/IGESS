# 05: 达到一周端到端至少两倍速度

**Status:** ready-for-agent

用户在首轮 486.488 → 429.597 秒后明确要求“至少比原来快一倍”。本票补充原四票的实施与验收，性能门槛以更新后的 [spec](../spec.md) 为准。

- [x] 保存后期真实存档，定位重复校验、查询、幸运值假投掷与大数成本。
- [x] 隔离候选提取源幸运值映射，真实投掷继续共用同一前置与完整结算。
- [x] 隔离候选合并默认源规则下的一次观察快照/完整校验，保留原公开 Query、写入校验和动态投影。
- [x] 首次观察包含幸运值，避免同一状态为成长观察再发完整查询。
- [x] 精确大数内部整数分块运算，6,573 项旧实现差分相同；保留精度和舍入。
- [x] 完成 double 路径差分、源回归、正式输出和恢复验证。
- [x] 一周正式串行配对中位数耗时不超过冻结基线一半；不能用局部热点或首日结果代替。
- [x] 最终复核、文档/技能同步、应用与范围内提交。



## Execution

实施与技术验收完成，用户验收待确认。最终首日/一周各三组串行配对全部等价，一周中位数达到至少 2 倍速度；完整测试、审查、身份及交付边界见[验证记录](../verification.md)。
