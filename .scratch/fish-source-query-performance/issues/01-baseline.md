# 01: 建立可复现的性能与结果对照

**What to build:** 从现有正式入口运行冻结的优化前版本，交付可重复的计时与业务产物差分。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 冻结当前实际代码、配置、只读导表和环境身份，不覆盖既有工作区修改。
- [x] 计时与比较工具接受运行身份参数，不覆盖历史证据；探针数据与正式测速分开。
- [x] 真实 Lua smoke 和首日基线成功，登记、报告、checkpoint 齐全。
- [x] 比较四份核心业务产物、源历史及行为存档；明确元数据差异白名单，故意改变业务数据时能检出。
- [x] 保留可重跑的旧版本，为最终串行交替测速提供基线。
