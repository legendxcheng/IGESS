# Fish 同源模拟性能验收

结论：本地实现达到用户“至少快一倍”的要求。同输入一周端到端中位数 **523.863 → 228.984 秒，2.29 倍速度，耗时减少 56.29%**，每次节省 294.879 秒。三组一周均更快，三组首日无回退；完整最终状态、四份核心产物和源恢复历史均一致。技术验收完成，用户验收待确认。

## 范围与实现

- 共享单次独立观察快照和完整 schema 校验，保留公开 Query/写流程的校验；投影失败回到原公开路径保留错误行为。
- 会话内缓存鱼厅稳定字段；动态余额、revision 和资格每次更新。完整背包一次评估/排序，保留公共分页与模拟原 DTO。
- 单次计算复用同鱼种/变异/等级的纯结果，可变大数独立；大整数身份不经短浮点字符串丢失。
- 幸运查询与真实投掷共用源映射，省去假奖励计算；异常规则/边界回退完整路径。首次状态查询含幸运值，避免同状态重查。
- 精确大数使用有安全整数界限的分块算法；JSON 只复用有界字段名并等价编码大数 DTO。
- 生产导表、经济公式、精度/舍入、策略、动作时点、随机、采样、事件、协议、回执及 checkpoint 身份契约保持不变。
