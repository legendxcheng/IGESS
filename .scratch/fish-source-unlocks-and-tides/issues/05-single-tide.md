# 05: 完整参与一场鱼潮

**What to build:** 已开放且装备合法枪的玩家完成一场鱼潮：预检预算与蛋位、六次源换弹扣费、120 秒前台占用、结束取得五颗随机蛋。

**Blocked by:** 03, 04

Status: claimed

本票执行《Fish 同源模拟：图鉴奖励、寻宝兽开放与鱼潮》规格；范围与边界以父规格为准。实现前在独立工作树确认基于当前集成分支，使用 tdd 技能；测试边界已获用户确认，无需再次询问。

- [ ] 采用 spec 的完整场预检：预算不足六次或蛋位不足五个时零扣费、零发蛋、零参与耗时并记录原因；先结算到期蛋。
- [ ] 开始时锁定枪与报价，通过源换弹服务和模拟 Native 适配器结算六次，费用零合法、非法费用明确失败。
- [ ] 参与恰好 120 秒且换弹时间包含其中；暂停投掷、锻炼及其他主动消费/装备切换，源后台生产持续。
- [ ] 结束时取得五颗随机蛋并经源服务入包；无提前孵化、无逐发命中或伤害收益映射。
- [ ] 场次、换弹及逐颗蛋有稳定身份，半途截断保存剩余时间；连续与恢复不重复扣费/发蛋/重抽。
- [ ] 源操作保存或通知延迟保留已受理事实；真实异常形成失败证据，不冒充正常完成。
- [ ] 正式事件和报告显示单场收益、六次实际费用、时间、阶段及近似标签；收入加回支出后不漏后台毛收入。
- [ ] 公开会话和正式工作流的红绿测试覆盖成功、金额边界、容量、途中恢复；合并集成分支后提交。
