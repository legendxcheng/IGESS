# 01: 单鱼图鉴奖励闭环

**What to build:** 玩家捕获普通鱼后可按鱼种与变异历史图鉴领取一次金币或材料，正式模拟会主动领取并在报告中独立展示收入。

**Blocked by:** None (can start immediately)

Status: ready-for-agent

本票执行《Fish 同源模拟：图鉴奖励、寻宝兽开放与鱼潮》规格；范围与边界以父规格为准。实现前在独立工作树确认基于当前集成分支，使用 tdd 技能；测试边界已获用户确认，无需再次询问。

- [ ] 沿用源图鉴目录和领取服务，排除关闭条目和神兽；重复捕获、出售、重生均不重置历史或奖励身份。
- [ ] 会话公开查询与命令接入 IGESS：默认按稳定奖励 ID 领取，每次 1 秒，解锁和领取时点分别记录。
- [ ] 源 BigNumber 金币/材料奖励及历史补领正确；失败不标已领，同请求与新请求重试不重复入账。
- [ ] 收入观察和正式报告区分图鉴一次性奖励、鱼厅转账和持续生产，系统开放统计不混入逐鱼领取。
- [ ] 测试经已确认的会话接口和正式运行边界，包含跨进程 checkpoint、防重、非法依赖和大金额；先红后绿。
- [ ] 能力声明、输入/代码摘要和运行包依赖随新增操作更新；生产导表只读。
- [ ] 提交前合并集成分支，记录两个仓库的提交和测试证据；不改无关生产行为。
