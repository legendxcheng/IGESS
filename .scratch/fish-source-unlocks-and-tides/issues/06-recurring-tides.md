# 06: 连续鱼潮与每日在线安排

**What to build:** 正式成长策略按源鱼潮间隔持续参与，正确处理开场、在线窗口、动作边界、离线错过和运行恢复，逐场结果可解释。

**Blocked by:** 05

Status: claimed

本票执行《Fish 同源模拟：图鉴奖励、寻宝兽开放与鱼潮》规格；范围与边界以父规格为准。实现前在独立工作树确认基于当前集成分支，使用 tdd 技能；测试边界已获用户确认，无需再次询问。

- [ ] 以固定且记录的房间原点按源绝对时间分槽，离线不冻结时钟、重连不重置、不补发，每场至多参与一次，仅开场边界入场。
- [ ] 计划下线剩余不足 120 秒跳过；场景截断与 checkpoint 不等于玩家下线，可保留进行中的鱼潮。
- [ ] 调度器避免普通动作非法跨开场；锻炼可源结算后停止，已提交投掷不可回滚，无法合法结束记录跳过。
- [ ] 同秒按 spec 顺序推进后台/到期事务、结束已有动作、判定鱼潮、选择普通动作；下线边界不新开动作。
- [ ] 参数、房间原点、落点/领取策略参与运行归因，能力缺失或非法配置在正式运行前诊断。
- [ ] 报告逐场参与/跳过、原因、累计在线耗时、蛋数、孵化数、换弹费用；不同采样间隔不改变业务结果。
- [ ] 跨日、119/120 秒、开场前后与多场 checkpoint 通过公开边界红绿验证；快速与逐秒推进等价。
- [ ] 提交前合并集成分支，记录双仓提交和测试证据。
