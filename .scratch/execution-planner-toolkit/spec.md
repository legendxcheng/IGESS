# 执行策划数值调优工具包

Status: implemented

## 目标

将 IGESS 的黑盒验证与数值调优能力交付给执行策划，同时通过源码隔离防止其在正常工作中接触或误泄露 IGESS 源码。安全目标不包含抵抗主动反编译。

## 职责边界

- 执行策划负责修改其自有 `.xlsx` 数值源表、导出 JSON、运行预设场景并查看调优报告。
- IGESS 只读取导表快照，不修改 JSON，不负责源表仓库的提交、评审或回传。
- 执行策划不负责定位代码根因或修复程序缺陷；内部异常通过诊断包交给 IGESS 所有者。

## 分发

- 源码仓库提供 `export-operator-toolkit`，输出到独立 Git 分发仓库的工作树。
- 首版运行环境固定为 Windows x64 + Python 3.11 x64。
- IGESS 本体与生成的 Fish schema 只交付 sourceless `.pyc`；不得包含 `.py/.pyi`、source map、测试或开发文件、版本库元数据、源码绝对路径。
- 第一方报表 JavaScript 使用压缩后的生产资产，不交付 source map；第三方资产保留许可证。
- 导出从临时空目录生成候选，白名单或泄露检查失败即停止，不提供跳过参数。
- 更新已有分发仓库时，只能覆盖或删除上一版交付清单声明由导出器管理的文件；清单外文件必须保留，新文件若与清单外文件冲突则停止。
- 导出器不执行 Git commit 或 push；所有者人工检查差异后发布。执行策划关闭工具后通过 `git pull` 更新。

## 调优工作台

- `start.bat` 检查 Python 3.11 x64 和公开第三方依赖，然后启动唯一用户入口。
- HTTP 服务只监听 `127.0.0.1`，完全离线，不使用 CDN、遥测、崩溃上报或自动更新。
- 首版提供：选择 JSON 目录、选择预设场景、运行模拟、查看报表、选择历史基线进行比较、查看固定回归结果、下载诊断包、手动删除历史。
- 不暴露参数扫描、Agent 建议、YAML 修改、模型编辑、事件源码追踪或开发诊断。
- 同一时刻只运行一个任务。

## 输入与历史

- 运行开始时一次性稳定读取输入目录中的 JSON 到临时快照并计算文件哈希；运行期间再次导表只影响下一次运行。
- 输入目录绝对只读，完整临时快照在任务结束后清除。
- 只验证当前引擎和场景实际读取的数据；未读取的数据不阻塞，实际依赖缺失或无效则失败。
- 历史写入 `%LOCALAPPDATA%\IGESS Operator\<model>\runs`，不写入分发仓库且不自动删除。
- 旧版本报告仍可查看；工具版本不同的历史不能作为比较基线。

## 诊断

- 工作台不显示 traceback、IGESS 源码路径或源码片段。
- 失败记录包含稳定错误编号、工具版本、输入文件名/大小/哈希和清洗后的消息。
- 诊断包默认不含完整 JSON；只有运行前明确勾选时，才在该次历史中保留并打包输入 JSON。

## 验收

- Fish 分发包可在 Python 3.11 x64 下脱离源码仓库读取生产 JSON 并成功完成 `smoke`、生成 Web 报表。
- 分发候选不存在 `.py/.pyi/.map`，且不包含源码仓库或项目的绝对路径。
- 导表输入在运行前后大小与修改时间不变。
- 同版本同场景可比较，跨版本比较被拒绝。
- 未勾选时诊断 ZIP 只有诊断元数据；勾选后才包含 `input/*.json`。
- 受控同步能移除旧清单拥有的陈旧文件，并保留所有清单外文件。
