# Fish 同源 Lua 数值执行器实施验证

日期：2026-09-24。源工程 `E:\fish-oasis`；IGESS 项目 `projects/fish_source`。测试边界采用用户确认的源执行器统一会话接口和 IGESS 正式 `model simulate` 入口，无 DS / PIE。

## 已交付

- 源项目 `simulation/` 装配原 Lua Application/Domain 服务，提供会话创建、查询、动作、虚拟时间、在线/离线、投掷生命周期、事件回执及跨进程 replay checkpoint。投掷服务与种子提供器增加隔离实例装配；正式玩法命令仍调用原服务。
- IGESS 的 `fish_source` 适配器负责画像时序和动作意图，源服务负责价格、资格、扣款、收益与业务状态。未支持的倍率画像、旧目标策略和运行假设在预检时拒绝。
- 以显式选定的 Fish JSON 导表为输入；每次运行冻结源 Lua 与导表，并记录内容摘要、Lua 版本、策略、seed、模型摘要。正式产物包括 timeline、events、analysis、Web 报告、同源成长/行为报告和最终 checkpoint。
- 鱼厅待领、已领和钱包可花费金额分开展示；双 Luck 无法由源计算时记缺失。旧 Python 项目保留历史运行；新策略与旧策略不是可直接对比的单因素实验。

## 当前限制

- 新后端由独立 `projects/fish_source` 显式选择；未将旧 `projects/fish` 默认切换。旧画像目标选择不等于新策略，付费倍率不支持。此状态不标记为已完成默认迁移。
- 现有 authoring 通用 `Datas/` 与 `luban_exports/` 是结构输入，真正 Fish 数值来自 `engine.source_runtime.data_root`；修改通用工作簿不会改变 Fish 源数值。
- Web 报告现已接入同源产物，恢复力量、双 Luck、投资、钱包/待领、按日和按周的成长操作面板；旧长场景只有按天状态采样，完整 5 分钟在线毛产出和精确停滞仍缺失。修复证据见 [报表可读性回归](../fish-source-report-readability/verification.md)。
- `week_1_growth` 和 `month_1_growth` 配置中的 `compact_event_details` 尚未应用于同源后端；运行保留完整命令回执，长期场景的事件文件较大。
- 最终 checkpoint 可重放并恢复活动中状态，但正式运行尚未周期性落盘中途 checkpoint。当前导表摘要覆盖选定目录全部 JSON，因此无关 JSON 改动也会拒绝旧 checkpoint。
- 7 天最终 checkpoint 已跨进程恢复；30 天仅验证生成和指纹，尚未对该大历史 checkpoint 执行完整恢复。
- 不含 UE 世界、DS、网络、碰撞和真实玩家路径；“同源”只指已覆盖的游戏业务服务。业务覆盖和新策略尚需扩展，不能宣称 100% 真实玩家结果。
