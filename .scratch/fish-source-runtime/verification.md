# 同源 Lua 数值执行器：首条业务链验证

日期：2026-09-24。范围：源项目独立 Lua 会话、选定导表 JSON 加载、跨进程接口与 IGESS 进程客户端。**尚未接入正式 `model simulate`，不是完整规格验收。**

## 已实现的可验证行为

- 源项目宿主直接调用现有存档、生产、鱼厅和杠铃 Application 服务；支持创建会话、查询、推进虚拟时间、摆鱼、逐槽领取、杠铃合成/装备与开始/停止锻炼。
- 端到端案例覆盖鱼在背包中、摆入鱼厅、推进 10 秒、产出停留在槽位、逐槽领取后进入可花费钱包、领取重试不重复入账、合成消费 20 金钱、1.5 秒锻炼完成 3 个半秒周期。
- 子进程通过 JSON Lines 接口调用；游戏日志写标准错误，协议只写标准输出。Lua 运行时版本经客户端校验。
- 导表 JSON 在会话建立时读入内存，游戏表管理器按生成 schema 加载；隔离复制快照改变鱼厅价格后，查询读取的是该选定快照的值。
