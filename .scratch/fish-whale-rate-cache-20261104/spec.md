# 神兽纯产出缓存

范围：缓存神兽同种倍率和精确参照产出乘积；复用同一决策已查询的动作报价。保留源公式、验证顺序、金额精度、结算和策略顺序。

- 倍率依赖：规则行、基础倍率、同种额外倍率、合法数量；每行最后一项，弱键释放。
- 神兽产出依赖：规则行、已验证的参照大数与源倍率完整 sign/coeff/exp；每行最后一项，输入对象不被持有，返回大数独立。普通鱼选择和升级、变异、部署变化先走源规则更新参照。
- 动态余额、公共倍率、生产秒数、随机与回执不缓存，不添加存档字段。
- 验证：缓存热启动后的依赖变化、非法输入、返回值污染、跨规则隔离；冻结同一输入的正式短场景配对、逐次查询差分、核心产物与真实跨进程恢复。
- 测量：三组串行两小时大 R 场景，另检月末鱼群短测；不将其直接外推为完整月模拟耗时。
