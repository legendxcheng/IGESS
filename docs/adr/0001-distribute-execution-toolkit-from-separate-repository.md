# 通过独立 Git 仓库分发执行工具包

IGESS 源码仓库提供导出能力，将固化的模型规则、预设场景和运行能力生成为裁剪后的执行工具包；生成物进入独立的分发仓库，执行策划只拉取该仓库并以导表快照作为数值输入。导出必须从空目录按白名单生成发布候选并执行源码泄露检查，工具不得自动提交或推送，只有所有者人工检查后才能发布。该边界以方便本地使用和版本更新为代价，避免向执行策划开放源码仓库，同时不承诺抵抗对本地交付物的主动逆向。

分发仓库是单向的软件交付渠道。执行策划在其自有的 `.xlsx` 源表仓库中管理和提交数值变更，IGESS 不负责该仓库的评审、同步或回传流程。

调优工作台不自动联网或更新。执行策划关闭工具后，通过分发仓库执行 `git pull` 获取所有者已人工确认的版本。

导出器通过上一版交付清单识别其管理的文件。更新分发仓库时，它只能删除该清单明确归属导出器、但新版本已不再生成的文件；必须保留 `.git` 和清单之外的所有内容，并生成新清单供所有者检查。

发布候选必须通过不可绕过的交付白名单与源码泄露检查。发现 IGESS `.py/.pyi`、source map、版本库元数据、测试或开发文件、源码绝对路径，或任何未获准文件时，导出立即失败且不得标记为发布候选。
