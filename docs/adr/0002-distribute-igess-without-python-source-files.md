# IGESS 本体不以 Python 源文件交付

执行策划可以自行安装 Python 和公开第三方依赖，但普通源码 wheel 会把 IGESS 的 `.py` 文件暴露在本机，违背源码隔离目标。因此，首版分发仓库只交付 Python 3.11 sourceless `.pyc` 字节码以及锁定的第三方依赖安装方式；导出流程在编译后删除全部 IGESS `.py`，清理构建路径信息并扫描发布候选。这不用于抵抗主动反编译，但能防止正常工作中的源码接触与误泄露，首版不引入 Nuitka 或 PyInstaller。

首版唯一受支持的执行环境为 Windows x64 与 Python 3.11 x64。启动器必须在运行前检查该环境并为不匹配情况提供中文修复提示。

调优工作台的本地服务必须固定监听 `127.0.0.1`，不得绑定局域网或公网地址。

调优工作台完全离线运行，不使用 CDN、遥测、崩溃上报、在线字体或自动更新。所有前端资产随执行工具包提供，运行时只访问用户选择的本地输入和本地运行历史。

浏览器运行所需的第一方 JavaScript 只交付压缩后的生产构建，不包含 source map、注释或源码目录结构；公开第三方前端资产可以随许可证一并交付。前端产物同样只防止日常源码接触，不承诺抵抗主动分析。

执行策划自行安装 Python 3.11 x64 和锁定版本的公开第三方依赖。分发仓库只提供依赖清单与安装说明；启动器检查 Python 版本和依赖，缺失时显示安装命令，但不得创建虚拟环境、联网或自动安装。
